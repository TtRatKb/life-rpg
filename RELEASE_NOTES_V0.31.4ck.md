# Life RPG V0.31.4ck — Procreate-style Creative Canvas Shell

## Core interaction
**Finger = canvas navigation. Pencil/mouse = drawing.**

## Drawing Studio
- Starting a challenge switches into a canvas-first workspace with the reference/colors/tools dock fixed at the right edge.
- Finger touches can no longer create strokes, erase, smudge or pick colors.
- Two fingers now pan and pinch-zoom at the same time, anchored under the gesture midpoint.
- Apple Pencil / other pen pointers keep pressure-sensitive drawing. Mouse drawing and desktop wheel/trackpad zoom still work.
- Added a live zoom indicator and unobtrusive gesture reminder.
- Browsing and challenge briefings stay in the existing full interface; the compact Procreate-like shell appears only during practice.

## Coloring Studio
- The coloring canvas is now the dominant center area.
- Coloring-card library becomes a slim left rail; colors/brushes/tools remain in a fixed right-side dock.
- Finger touches can no longer paint, erase, fill, smudge or use the pipette.
- Two fingers pan and pinch-zoom the card.
- Apple Pencil / pen and mouse remain drawing inputs.
- Existing color wheel, fill, soft brush, smudge, eyedropper, undo/redo and export remain intact.

## PWA
- Cache version bumped to `0.31.4ck` so both creative studios refresh reliably.
