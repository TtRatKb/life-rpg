# Life RPG V0.31.4cg — Drawing Studio Practice Paths

## Added
- Expanded Drawing Studio from 12 to **30 structured drawing challenges**.
- Exactly **5 challenges per practice track**: Dynamic Figures, Hands & Anatomy, Faces & Hair, Perspective & Backgrounds, Color & Rendering, Story Illustration.
- Track cards now show **unique challenge progress** (e.g. 2/5).
- Challenge cards show their **path step** and mark the next unpracticed challenge as **NEXT**.
- Recommended view now surfaces the next useful challenge across tracks, while still using recent trouble-tags when available.
- Challenge briefings now include a **Practice Path position** plus curated learning links to relevant external practice/tutorial sources.
- Added built-in guide layouts for all newly added challenges.

## New challenges include
Balance Check Pose, Two Characters One Reaction, Body Proportion Debug, Head Turn Sheet, Expression Quartet, Hair in Action, Two-Point Street Corner, Café Corner, Character in Space, Foreground/Midground/Background, Single Light Source, Warm Light/Cool Shadow, Limited Palette, Same Sketch 3 Moods, Tiny Composition Thumbnails, Moment After, Two Characters One Action, and Mini Story Illustration.

## Notes
- No hard locking: the suggested order is guidance, not a restriction.
- Coloring Studio remains unchanged.
- Existing Drawing Studio practice history and rewards remain compatible.
