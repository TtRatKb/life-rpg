# Life RPG V0.31.4ch — Drawing Reference Pack V1

This pass upgrades Drawing Studio practice from abstract canvas guides to a first built-in local reference library.

## New
- 12 original built-in practice references, stored locally and available offline.
- Reference coverage for:
  - dynamic figure / gesture
  - torso twist and pose construction
  - open-hand construction
  - hand + object interaction
  - 3/4 head construction
  - hair flow in motion
  - one-point room perspective
  - two-point street perspective
  - three-value rendering
  - warm-light / cool-shadow studies
  - story staging
  - two-character shared action
- Relevant challenges now show a **BUILT-IN REF** marker.
- The right-side Reference panel now includes an image viewer with previous/next navigation.
- Clicking a reference opens a larger clean study view.
- Challenge briefings show the first built-in reference before the canvas starts.
- External Line of Action / Proko / Ctrl+Paint resources remain available as optional additional practice sources.
- All included references are original Life RPG practice assets rather than copied third-party artwork.

## Intent
These assets are construction/study references, not finished illustrations the user is expected to imitate perfectly. They are designed to make the exercise goal visually clear while leaving room to adapt the pose, character, styling and story.
