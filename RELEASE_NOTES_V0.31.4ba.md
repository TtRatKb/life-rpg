# V0.31.4ba — Relationship Life 2.0

- Adds persistent relationship memory reconstructed from existing story/social choices, gifts and seasonal moments.
- People can now reuse previously learned preferences, care boundaries and household decisions in later Talks, Messages and World Moments.
- Adds 10 memory-reactive Talks, 3 memory-reactive Message threads and 4 memory-reactive World Moments.
- Gift keepsakes can be referenced again later; generic liked/loved gift history can create callbacks without exposing hidden Affection values.
- Adds a subtle Shared Threads section to People profiles. It shows remembered shared history, never Friendship/Affection numbers.
- Existing saves are backfilled from already-made choices, so prior relationship history is not lost.
- Relationship memory is non-punitive: forgetting/absence never reduces hidden relationship progress, and the system does not create mandatory social upkeep.
