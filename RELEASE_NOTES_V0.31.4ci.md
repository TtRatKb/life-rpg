# Life RPG V0.31.4ci — Drawing Reference Packs V2

## What changed
This pass expands the Drawing Studio's built-in practice references from single/example references into small browseable practice packs.

### Expanded reference content
- 44 local practice-reference assets total.
- More dynamic figure variations: reach, crouch/launch, landing, turning, pulling and twisting.
- More hand construction: open palm, fist, pointing, foreshortened palm, mug grip, phone grip and fabric pinch.
- More head-angle construction: front, 3/4, profile, looking up and looking down.
- More hair-motion references: turn, side wind, falling forward and spin-back flow.
- More perspective/environment references: room, hallway, café booth, bedroom corner, low-angle room and character scale in space.
- More story-interaction references: shared action, catch/fall, doorway surprise, argument, shared weight and letter discovery.
- More rendering/color references: 3-value grouping, side light, backlight, limited palette and three mood palettes.

### Reference Pack UX
- Challenge cards now show the number of references in their built-in pack.
- Briefings show the pack size before starting.
- The right-side reference viewer now has clickable thumbnails.
- Previous/next navigation remains available.
- Added a Random button for quickly switching to another reference in the same pack.
- Enlarged reference dialog still works for any selected reference.

## Compatibility
- Builds directly on V0.31.4ch.
- Existing drawing saves, practice history and rewards are unchanged.
- Coloring Studio is untouched.
