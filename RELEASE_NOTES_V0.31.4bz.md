# Life RPG — V0.31.4bz

## Coloring Studio cleanup
- The approved **Bakugo Trading Card** is now the only current Coloring Studio page.
- Coloring Studio is now a **single permanent Talent unlock**. New self-generated coloring cards can be added to its library later without buying additional Coloring Studio ranks.
- Existing Rank II owners are migrated to Rank I automatically. The extra Hobbies Talent point becomes available again because Rank II no longer exists.
- Old Bakugo/Kirishima/DynaRiot starter pages are no longer referenced by the runtime.

## Permanent access
- Once Coloring Studio is unlocked, a dedicated **🖍️ Coloring** button appears in the main navigation after Games.
- You no longer need to return to the Hobbies Talent Tree just to open the studio.

## Talent Tree stability
- Talent purchases/respecs now save without triggering an unnecessary app-wide UI refresh.
- The Talent Tree updates itself in place, preventing the Skills page from jumping away from the active tree after a purchase.
