# Life RPG V0.31.4co — Existing Hands + Duo Reference Sets

This patch intentionally uses **existing third-party reference material** rather than generated placeholder reference art.

## Added reference packs

### Hands & Gestures
- **Character Hand Drawing Reference** by Umang Thapa / Umangzart — CC BY-SA 4.0
- **Hand pose illustration** by Shiva Theerthagiri — CC BY 4.0
- **24 hand gestures from Chirologia** via Wellcome Collection — CC BY 4.0

These appear in hand-focused Drawing Studio challenges and stay visible in the existing dock / floating reference / underlay workflow.

### Duo / Interaction
- **JookpubStock Conversation series**: 9 existing two-person pose references from Wikimedia Commons.
- License: CC BY 3.0.
- Used for story, interaction and two-character practice challenges.

## UX
- Existing reference pack thumbnails can be browsed directly in the fixed reference dock.
- Previous / next / random work with the new sets.
- Floating reference and underlay follow the selected set reference.
- Attribution and license links are displayed in the reference panel.
- Briefing gets a small preview of the active existing reference set.

## Important
No generated hand or duo reference sheet is included in this patch.
