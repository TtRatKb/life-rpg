# Life RPG — V0.31.4ag4

## Hobbies Talent Tree
Adds the seventh and final current Realm Talent Tree to the Skills hub.

### Nodes
- Hobbies Compass
- Creative Spark
- Maker's Bench
- Style Atelier
- Play Shelf
- Creative Thread
- Hands-On Return
- Lookbook
- Leisure Loop
- Life in Color

### Real utilities
- Starts actual Hobbies timers for Creative, Music and Craft.
- Routes to existing Songwriting, Music Composition, Craft Session and Scrapbook quests.
- Uses the existing Inspiration Library and the real hairstyle / makeup try flow.
- Surfaces existing for-fun books and Hobbies games, and opens their normal log dialogs.
- Surfaces active Hobbies Adventures without generating generic project plans.
- Keeps recent Craft & Making and Recreation & Play routes easy to resume.
- Hobby Shuffle chooses only among real available routes and softly favors the Hobbies skill that has been quietest recently.
- Life in Color adds +1 Hobbies Realm XP to the first actual Hobbies skill practice after unlock each day.

### Guardrails
- Recreation is treated as legitimate life balance, not a generic “Gaming Skill”.
- Opening media, an inspiration, a quest or an Adventure never awards Skill XP by itself.
- No streak, missed-day penalty, balance quota or requirement to use all four branches.
- Existing Games, Library, Inspirations, Adventures and Hobbies quests remain available without talents.
- Free respec cannot replay previously earned talent bonuses.
