# Life RPG — V0.31.4ag2

## Japanese Talent Tree
Adds the fifth real Realm Talent Tree to the existing Skills hub.

### Nodes
- Japanese Compass
- Review Pocket
- Grammar Trail
- Immersion Shelf
- Due Compass
- Active Echo
- Return Ticket
- Everyday Japanese

### Real utilities
- Reads the existing Kotoba connection and due snapshot.
- Starts existing Tiny / Quick Japanese sessions through Kotoba's real SRS bridge.
- Can manually refresh Kotoba due state.
- Starts the existing timed Bunpro Review Block as a linked quest timer.
- Opens Bunpro Lesson, Shadowing and Line Miner in the real Quest Board rather than auto-completing them.
- Surfaces existing Japanese-tagged books and games without duplicating the Library.
- Keeps the most recently logged Japanese immersion route one tap away.
- Keystone Smart Japanese chooses a current route from real due state / available Bunpro review / recent immersion / Japanese quests.
- Keystone adds +1 Japanese Realm XP to the first actual Language Learning practice after unlock each day. Opening a shortcut earns nothing.

### Guardrails
- No streak requirement or missed-day penalty.
- Existing features are never locked behind talents.
- No XP is awarded for merely opening a tool, book, game or quest.
- Free respec remains enabled and cannot replay already-earned talent bonuses.
