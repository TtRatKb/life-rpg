# Life RPG — V0.31.4bw

## Coloring Studio: full color wheel
- Added a continuous color wheel instead of relying only on preset swatches.
- Distance from the center controls saturation; angle controls hue.
- Added a brightness slider from 0–100%, so the picker can reach dark tones and black as well as bright colors.
- Added an exact HEX color field for direct RGB color entry (for example `#FF6A3D`).
- The selected color is previewed live and remains compatible with the existing brush, Apple Pencil pressure, undo/redo, autosave and PNG export.
- Existing quick-color swatches remain available underneath the color wheel.
