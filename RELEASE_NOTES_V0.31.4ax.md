# Life RPG V0.31.4ax — Dreamscape Content Expansion

## Dream library
- Doubles the Dreamscape library from 42 to 84 authored dreams while preserving every existing dream ID and archive entry.
- Every Realm / Thread tier / character focus now has at least two distinct dream scenarios instead of a single repeating template.
- New dreams use more realm-specific situations and stronger differences between soft Thread I dreams and deeper Thread II dreams.
- Bakugo, Kirishima and Both remain automatic hidden-affection-weighted focus rolls; there is still no player route picker before a dream.

## Variety / RNG
- Unseen dreams are strongly favored.
- After the unlocked pool has been seen, the system avoids the most recently read dream IDs where possible.
- Recent Realm damping remains in place.
- Tier II dreams get a modest weight boost once that Realm's second Dream Thread is actually owned.
- A pending dream is still saved immediately, so reopening cannot reroll the result.

## Dream Archive
- Archive now displays unique dreams rather than duplicate rows for repeated reads.
- Repeat reads are counted on the dream card.
- Adds filters for Bakugo / Kirishima / Both and Realm theme.
- Shows unique discovered count, currently unlocked pool size and total library size.
- Replay remains free and never changes cooldown, canon flags, Story Energy or hidden relationship state.

## Compatibility
- Existing Dreamscape state/schema and archived dream IDs remain valid.
- No canon story state or Affection is changed by Dreams.
