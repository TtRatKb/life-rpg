# Life RPG — V0.31.4ah

## Skills + Talent Tree cohesion polish

- Adds Realm-rank points at a tuned rate of +1 point per Realm rank-up.
- Adds breadth milestones in Realms with 3+ skills: Foundation +2, Versatility +3, Mastery +5.
- Keeps existing node costs unchanged to avoid retroactively repricing already-unlocked talents. Current full trees cost 14–18 points.
- Talent tabs now show available points and tree completion.
- Active-tree summary shows point sources, spent points, full-tree cost and next unlock.
- Unified node badges: Unlocked / Ready / Need points / Path locked.
- Realm skill cards now link directly back to their own Talent Tree.
- Medium and mobile layouts are normalized across all seven trees; talent tabs stay reachable while scrolling.
- Talent utility cards use an adaptive grid to reduce unnecessary vertical scrolling.
- Arrow keys/Home/End navigate Talent Tree tabs.
- Skill XP formula, one-action-one-skill rule, tree effects and free respec behavior are unchanged.
