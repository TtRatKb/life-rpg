# Life RPG — V0.31.4ao

## Talent Tree Paths + Content Expansion

This pass keeps Talent Trees V2's real reward mechanics, but restores an actual visible tree structure and adds meaningful content goals across every Realm.

### Tree layout
Each Realm now visibly splits from a Realm Point root into three branches:
- **Rewards** — Reward Cache I–V.
- **Power & Momentum** — Resonance I–V → Momentum I–III → Realm Special I–III.
- **Content** — real permanent unlocks branching from the Realm Special.

Connector lines, prerequisite labels and locked nodes show exactly what must be bought before the next target.

Existing V2 ranks and unlocks are preserved. There is no second refund/reset migration.

### New real content unlocks
- **Work:** Work Debrief → Lesson Spark Deck.
- **Knowledge:** Decision Lens.
- **Japanese:** Sentence Forge.
- **Health:** existing Thought Untangler stays as the real content node.
- **Recovery:** existing 5–4–3–2–1 Grounding stays as the real content node.
- **Home:** One-Surface Reset.
- **Hobbies:** Creative Prompt Deck → Idea Garden.

All newly-built content unlocks cost Realm Points and remain permanently owned after purchase/respec.

### New content surfaces
Work Debrief, Decision Lens, Sentence Forge and Idea Garden appear as locked/unlocked optional cards inside Journal. Their writing rewards are modest, tiered, and only earned by actually writing.

One-Surface Reset launches a real 7-minute Home/Life Rhythm timer.

Lesson Spark Deck draws a concrete teaching/design prompt and launches a real 25-minute Focus session.

Creative Prompt Deck draws a low-pressure creative prompt and launches a real 15-minute Hobby timer. Because ordinary hobby time is reward-neutral, completing the unlocked prompt session has a small dedicated completion reward.

### Future visible branches
Future nodes remain visible but **not purchasable** until the content exists:
- Work Focus Challenge Deck
- Logic Expansion (Slitherlink/Nurikabe direction)
- Japanese Shadowing Sprint
- Health Body Signals
- Recovery Toolkit
- Home Reset Deck
- Hobbies Creative Dice

This keeps the tree aspirational without repeating the old Study Compass problem.

### Point accounting
New content spending is included in available/spent Realm Point totals even though the core V2 state remains backward-compatible.

### No retroactive locking
Nothing that already existed in Life RPG was moved behind a talent. Only newly-added optional content is locked.
