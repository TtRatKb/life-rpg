# Life RPG V0.31.4cl — Curated Pose Packs V1

This pass replaces the most generic one-off figure references with small curated multi-image packs while keeping the Procreate-style canvas shell from CK intact.

## New curated packs

### AdorkaStock · Dynamic Action
Five public pose references focused on movement, turns, jumping and camera depth. Used by the Gesture, Push the Pose and Action Mannequin challenges.

### AdorkaStock · Foreshortening
Three high-/low-angle studies for proportion debugging and difficult camera depth.

### AdorkaStock · Interaction & Story
Three multi-person references focused on pulling, supporting, shared weight and two-person staging. Used by reaction/story challenges.

## Reference dock behavior
- Packs stay visible in the fixed right-side dock while drawing.
- Thumbnail switching, Previous/Next, Random, floating reference and underlay mode all continue to work.
- The dock now shows the actual curated pack name instead of a generic “Practice pack” label.
- Briefings identify the current pack before the challenge starts.

## Source / license
The included web references are public AdorkaStock pose-reference photos displayed from AdorkaStock's website. Each item keeps its source page, `AdorkaStock` credit, and `CC BY 3.0` label visible in the reference dock. The image files are not repackaged inside this ZIP.

Internet access is required for these particular reference images.
