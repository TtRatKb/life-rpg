# Life RPG V0.31.4cn — Commons Pose Packs Hotfix

This replaces the AdorkaStock hotlinked image URLs that were still failing in Safari/GitHub Pages.

## What changed
- Removed AdorkaStock-hosted image files from the active curated packs.
- Rebuilt the curated packs from **JookpubStock reference sets hosted on Wikimedia Commons**.
- The JookpubStock files on Commons are licensed **CC BY 3.0** and attribution stays visible in the Reference Dock.
- Added cohesive packs for:
  - Jump / Run / Fall gesture practice
  - Camera Angle & Foreshortening
  - Conversation / Two-Person Staging
  - Story Props & Quiet Beats
- Reference images now come from Wikimedia Commons, which is substantially more reliable for embedded cross-origin images than the previous direct AdorkaStock hotlinks.
- Service worker and Drawing Studio cache version bumped to `0.31.4cn`.

## Important
The old locally generated SVG guides are still available as guides where useful, but the active photo reference packs no longer depend on the broken AdorkaStock hotlinks.
